# Changesets

Changesets record which packages should receive a release and describe the change for users.
Their summaries become published changelog entries.

Write for a web developer using Starwind. Start with the visible fix or new capability, name
the affected component, and explain when the change matters. Keep sentences short. Include API
details when users need them, and state required update steps in a separate paragraph.

Example: "Fixed nested overlays in Vue and Svelte, including Select menus appearing behind a
Color Picker."

Follow [Release Note Writing and versioning policy](../docs/release/versioning.md).
Keep matching docs changelogs consistent. Wording changes must preserve package selections,
version bumps, and required migration guidance.
